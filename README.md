# Monterey Sea Otters

A multi-page HTML/CSS website about Monterey sea otters, served with a small Express static server.

Originally Project 1 for INFO6150 (Web UI/UX Engineering).

## Pages

- `index.html` — home page
- `about.html` — about page
- `register.html` — registration form, submitted to a server-side `/register` endpoint that echoes back the sanitized input

## Running

```bash
npm install
node server.js
```

Then visit `http://localhost:3000/`.
